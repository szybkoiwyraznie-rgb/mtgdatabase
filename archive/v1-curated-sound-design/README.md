# Archive: v1 curated sound design

This directory keeps the old manually curated/layered sound-design system:

- gates and listening candidates,
- semantic taxonomy and resolver data,
- approved block libraries,
- layered recipes,
- old generated signatures,
- old v1 helper scripts and audits.

It is intentionally no longer used by the production ZIP or Pages gallery.
The current product starts from zero and uses `data/samples/*.jsonl` scenarios
plus one generated short homogeneous sample in `audio/samples/<id>.mp3`.
