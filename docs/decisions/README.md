# ADR-y

ADR (Architecture Decision Record) opisuje istotną decyzję techniczną lub procesową. Nowy ADR powinien mieć numer, status, datę, decyzję, uzasadnienie i konsekwencje.

Agenci zapisują tu decyzje, które będą ważne dla kolejnych iteracji. Nie używaj ADR-ów do krótkich notatek roboczych; te trafiają do raportu PR albo `docs/LESSONS.md`.
